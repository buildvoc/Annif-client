# Building Wiki Schema

## Purpose

Maintain a source-backed building/place knowledge base from DoclingDocuments.

## Rules

- Never modify files in raw/.
- No source = no claim.
- Uncertain match = mark as Needs verification.
- Do not merge nearby buildings without evidence.
- Prefer authoritative IDs over names.
- Keep page names lowercase and hyphenated.
- Always update wiki/index.md and wiki/log.md after wiki changes.

## Page types

- wiki/sources/source-name.md
- wiki/buildings/building-name-or-id.md
- wiki/places/place-name.md
- wiki/streets/street-name.md
- wiki/collections/collection-name.md
- wiki/themes/theme-name.md
